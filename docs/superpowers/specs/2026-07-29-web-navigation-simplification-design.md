# Web 导航与聊天记录精简设计

## 目标

把 Web 控制台从功能罗列式导航收敛为八个明确入口，并把已经完成的“聊天总结”交互直接作为“聊天记录”的唯一 Web 用法。

## 导航结构

保留以下入口，顺序不变：

1. 总览
2. 初始化
3. 聊天记录
4. 消息搜索
5. 联系人
6. 群聊成员统计和导出
7. 单个聊天数据统计
8. 群聊成员邀请统计

移除“最近会话”“聊天总结”“导出”“收藏”“未读与新增”入口及其对应页面。会话列表 API 仍作为聊天记录下拉选择器的数据源，不在导航中单独暴露。

## 页面行为

- 总览只保留状态面板，去掉右侧快捷操作，状态面板占满内容区。
- 聊天记录使用可搜索下拉框选择会话，使用原生日期选择器按天选择开始和结束日期。
- 聊天记录结果继续提供“复制”和“复制精简信息”；前者带 AI 总结要求和全部已读取记录，后者只保留会话范围、时间、发言人、类型和正文。
- “群成员”“统计”“邀请统计”只调整 Web 导航与页面标题，不改 CLI 命令和后端接口。
- 群聊成员邀请统计页明确注明：“统计范围：从微信数据库记载的日子开始。”结果仍以数据库当前可见的系统提示为准。

## 兼容性与隐私

- `sessions`、`history`、`export`、`favorites`、`unread` 等 CLI 命令继续保留，仅精简 Web 界面。
- 聊天记录页不上传聊天内容，预览时不加载远程头像和远程媒体。
- 各页面结果继续独立保存和恢复。

## 验收

- 导航仅出现八个保留入口，已删除名称和页面均不再存在。
- 总览没有快捷操作。
- 聊天记录页包含会话搜索下拉、两个日期选择器、整理按钮和“复制精简信息”按钮。
- 邀请统计页面显示数据库起始范围提示。
- 完整自动测试、浏览器真实数据测试和 Windows 交付包验证通过。
