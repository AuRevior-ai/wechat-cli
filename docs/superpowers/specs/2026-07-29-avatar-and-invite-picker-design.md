# 真实头像与邀请统计群聊选择器设计

## 目标

1. “群聊成员邀请统计”使用只包含群聊的可搜索下拉框，避免手输群名。
2. 邀请统计起止时间改为原生日期选择器，同时允许留空，以保留“从数据库最早记录开始”的默认语义。
3. 消息中的对方、本人及群聊使用真实微信头像；左上角品牌位置显示当前微信账号头像和昵称。

## 数据与交互

- `sessions` JSON 增加 `avatar_url`，现有字段保持不变。
- 聊天记录与邀请统计共享一次会话加载；邀请统计只筛选 `is_group=true` 的会话。
- 下拉框展示群聊头像、群名、最近时间和稳定的 `@chatroom` 账号；表单提交稳定账号。
- 邀请统计日期使用 `type="date"`。两个日期都可留空，填写时仍按整天传给现有 CLI。
- 聊天记录结果保留群聊顶层 `avatar_url`，在结果抬头展示群头像；消息列表显示发送者头像，包含本人消息。

## 本机头像代理

- 浏览器不直接连接微信头像 CDN。所有 HTTP(S) 头像 URL 转换为 `/api/avatar?url=...`。
- 头像代理只允许 HTTPS，且域名必须属于 `qlogo.cn`、`qpic.cn` 或 `weixin.qq.com`。
- 代理验证最终重定向地址、图片 Content-Type 和 2 MiB 大小上限，并在进程内做有界缓存。
- `/api/profile` 从当前配置推导本人稳定账号，复用联系人命令取得昵称和头像 URL。
- 头像缺失、过期或下载失败时继续显示首字占位，不影响聊天和统计主流程。

## 视觉

- 延续现有纸张/账本风格，不重做整体布局。
- 左上角头像使用圆角方形，与当前品牌标记同尺寸；昵称显示在 `WeChat CLI Web` 下方。
- 消息头像和下拉框头像保持当前尺寸，仅把首字占位替换为图片。

## 验收

- 邀请统计群聊框可搜索并只能选群聊，日期框均为日历控件。
- 左上角显示当前账号 `Au Revior` 及其真实头像。
- 目标群聊天记录中本人和群友使用本机代理头像；页面不存在直接指向外部域名的 `<img>`。
- 头像代理拒绝非允许域名和超大/非图片响应。
- 完整测试、浏览器真实数据测试和 Windows 0.2.9 安装包验证通过。
