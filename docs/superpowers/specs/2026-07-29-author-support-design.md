# 作者署名与支持页面设计

日期：2026-07-29  
状态：已确认  
作者署名：Au Revior

## 目标

在不干扰微信数据读取和统计操作的前提下，为 WeChat CLI Web 增加稳定、易发现的作者署名和支持入口，并将作者微信二维码、微信收款码随 Windows 程序离线交付。

## 已确认布局

采用“侧栏底部入口 + 独立页面”方案。

1. 左侧品牌区域继续显示当前微信账号头像和名称。
2. 品牌区域新增次级署名“作者 Au Revior”。
3. 左侧导航底部固定“关于与支持”入口，与主要数据功能保持视觉分隔。
4. “关于与支持”页面包含作者简介和两张二维码卡片：
   - “添加作者微信”：使用 `个人码.jpg`。
   - “支持作者”：使用 `收款码.jpg`。
5. 二维码可点击打开本机原图，以便清晰扫码。

## 视觉要求

页面沿用现有纸张纹理、墨色文字、深绿色强调色和紧凑工具感，不引入新的设计体系。

- 署名层级低于应用名称和当前微信账号，不抢占品牌主视觉。
- “关于与支持”入口固定在侧栏底部。
- 二维码卡片在桌面端并排，在窄屏端纵向排列。
- 个人二维码采用蓝色识别标签；收款码采用微信支付绿色识别标签。
- 图片保持原始比例，不裁掉二维码定位点、姓名或提示文字。

## 资源与服务方式

源图片来自：

- `C:\Users\28276\Desktop\个人码.jpg`
- `C:\Users\28276\Desktop\收款码.jpg`

它们将复制到源码的 Web 静态资源目录，并使用不含中文的稳定文件名。Web 服务只允许访问显式列入白名单的两张图片，不开放任意静态文件路径。

两张图片通过当前 `127.0.0.1` Web 服务提供，不上传到任何远程服务。现有 Host、Origin 和 CSP 限制继续生效。

## 作者信息覆盖范围

作者信息写入以下位置：

- Web 左侧品牌区域。
- Web“关于与支持”页面。
- Windows 交付说明。
- 项目 README。
- Python 项目元数据。

CLI 的数据输出格式不增加作者字段，避免破坏脚本和 JSON 消费者。

## 版本与打包

版本从 `0.4.0` 升级到 `0.4.1`。PyInstaller 构建必须包含两张静态图片，Windows ZIP 交付包和本机安装版本必须能够离线展示。

## 错误处理

- 图片加载失败时保留卡片标题和替代文字，不影响其他功能。
- 静态服务只接受已知文件名；路径穿越和其他文件名继续返回 404。
- 二维码页面不触发外部网络请求。

## 验收标准

1. 左侧品牌区域可见“作者 Au Revior”。
2. “关于与支持”入口固定在侧栏底部，切换页面后原有结果定档机制不受影响。
3. 两张二维码清晰、标签正确、点击后可查看本机原图。
4. 桌面和窄屏布局均可用。
5. 两张图片能从源码服务、冻结 EXE 和安装后的 `127.0.0.1:8787` 正常读取。
6. 未列入白名单的静态图片返回 404。
7. Windows 0.4.1 ZIP 包、Git 提交、全量测试和本机覆盖安装全部完成。
