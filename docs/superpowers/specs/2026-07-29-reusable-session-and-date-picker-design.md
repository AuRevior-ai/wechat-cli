# 可复用会话与日期选择器设计

## 背景

Web 控制台中“聊天记录”和“群聊成员邀请统计”已经分别实现了可搜索下拉选择，但两套代码互相独立；“消息搜索”“群聊成员统计和导出”“单个聊天数据统计”仍要求用户手工填写名称或日期。重复实现也导致加载、错误重试、键盘操作、头像和账号切换行为不一致。

## 目标

提供一套可复用的会话选择器和日期输入规范，并覆盖所有需要选择聊天对象或日期范围的页面：

| 页面 | 会话范围 | 选择模式 | 日期 |
| --- | --- | --- | --- |
| 聊天记录 | 全部会话 | 单选 | 开始、结束，默认当天 |
| 消息搜索 | 全部会话 | 多选 | 开始、结束，可留空 |
| 群聊成员统计和导出 | 仅群聊 | 单选 | 无 |
| 单个聊天数据统计 | 全部会话 | 单选 | 开始、结束，可留空 |
| 群聊成员邀请统计 | 仅群聊 | 单选 | 开始、结束，可留空 |

## 交互设计

### 会话选择器

- 每个选择器都通过统一的 `data-session-picker` 根节点初始化。
- `data-filter="all"` 显示全部会话，`data-filter="group"` 仅显示群聊。
- `data-multiple="false"` 为单选，选择后写入隐藏参数字段并收起列表。
- `data-multiple="true"` 为多选，已选会话展示为可移除标签；隐藏字段以换行分隔用户名，继续兼容现有 CLI 参数读取。
- 搜索同时匹配会话名称和稳定用户名，空搜索按原会话顺序展示。
- 每个选项展示真实头像；头像不可用时回退到名称首字符。
- 支持方向键移动、Enter 选择、Escape 收起、鼠标点击和点击控件外部收起。
- 加载失败时每个选择器显示中文错误和“重试”按钮；账号数据刷新后统一清空选择并重新加载。
- 单选值始终使用稳定用户名提交，界面仅展示当前可读名称，避免同名或近似名称账号混淆。

### 日期选择器

- 所有日期范围统一使用浏览器原生 `type="date"` 图形化控件。
- 聊天记录默认开始和结束均为当天。
- 搜索、单聊统计和邀请统计保持可选，默认留空，便于查询全部已记载范围。
- 表单原有业务校验保持不变，例如消息搜索在没有关键词时仍要求完整日期范围。

## 技术设计

- 前端维护一份会话缓存，由 `/api/sessions?limit=5000` 提供名称、稳定用户名、群聊标识、未读数和头像代理地址。
- JavaScript 使用控制器数组管理任意数量的选择器；筛选、渲染、选中、清空、错误和重试均为通用函数，不再保留“聊天记录专用”和“邀请统计专用”分支。
- 页面切换时，仅当目标页面包含会话选择器且缓存尚未加载时发起请求。
- CSS 统一使用 `session-picker-*` 和 `date-input` 类，保留现有暖色视觉体系、焦点状态和移动端布局。
- 不改变后端命令参数结构；本次为前端交互重构，只增加必要的回归测试。

## 验收标准

1. 五个相关页面全部使用同一套会话选择器，四个相关页面全部使用图形化日期输入。
2. 群聊限定页面不会显示个人会话；全会话页面可选择个人或群聊。
3. 消息搜索可以添加多个会话、移除标签并正确提交。
4. 所有选择器都显示头像、支持搜索与键盘操作，并共享加载失败重试。
5. 切换账号或重新初始化不会残留旧账号的选择值或头像。
6. 既有命令与 API 测试通过，浏览器逐页验收通过。
7. 版本提升为 `0.3.0`，生成 Windows 交付包并覆盖安装到本机。
