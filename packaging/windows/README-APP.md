# WeChat CLI Web 本地版

这是一个 Windows 本地工具包，用来把 WeChat CLI 的命令行能力变成网页界面。它只在本机启动 `localhost` 服务，适合不熟悉命令行的用户使用。

## 一键安装和启动

1. 解压整个压缩包。
2. 双击 `install-and-start.bat`。
3. 安装脚本会把程序复制到 `%LOCALAPPDATA%\WeChatCliWeb`。
4. 安装完成后会创建桌面快捷方式 `WeChat CLI Web`。
5. 浏览器会自动打开 `http://127.0.0.1:8787`。

使用网页控制台时，请保持弹出的命令窗口不要关闭。关闭窗口后，本地服务也会停止。

## 日常使用

安装后，直接双击桌面上的 `WeChat CLI Web` 快捷方式即可。

也可以手动运行：

```powershell
%LOCALAPPDATA%\WeChatCliWeb\start-wechat-cli-web.bat
```

## 第一次初始化

首次使用前请先打开并登录电脑版微信，然后在网页里进入“初始化”页面。

初始化会做两件事：

1. 自动查找本机微信数据目录。
2. 从正在运行的微信进程中提取本地数据库解密密钥（支持 Windows 微信 4.1+ 的口令派生方式）。

微信后续新建 `message_1.db`、`message_2.db` 等消息分库时，工具会在下次查询时自动识别并刷新密钥，不会继续静默读取旧分库。

如果同一台电脑登录过多个微信账号，初始化页面会列出检测到的多个 `db_storage` 目录。请先在下拉框中选择要读取的账号目录，再点击“开始初始化”。

如果初始化失败，请尝试：

- 确认微信正在运行并已登录。
- 右键以管理员身份运行 `start-wechat-cli-web.bat`。
- 点击“检测目录”重新扫描，或在网页初始化页面手动填写微信 `db_storage` 目录。

## 可用功能

网页端包含以下功能入口：

- 最近会话
- 聊天记录
- 群聊系统提示（包括“某人邀请某人加入了群聊”等原始提示）
- 消息搜索
- 联系人
- 群成员
- 聊天统计
- 聊天记录导出
- 收藏
- 未读消息
- 新增消息
- 初始化和重新初始化

## 隐私说明

本工具只绑定 `127.0.0.1`，也就是只允许本机访问。

它读取的是你电脑上的本地微信数据，不会把聊天记录上传到服务器。生成的配置和密钥保存在当前 Windows 用户目录下的 `.wechat-cli` 相关位置，请不要把这些文件发给别人。

## 常见提醒

- Windows 可能提示“未知发布者”或 SmartScreen 拦截，这是因为当前版本没有代码签名。确认来源可信后选择继续运行。
- 如果浏览器没有自动打开，可以手动访问 `http://127.0.0.1:8787`。
- 如果端口被占用，请关闭其他正在运行的 WeChat CLI Web 窗口后重试。
- 如果要卸载，可以删除 `%LOCALAPPDATA%\WeChatCliWeb`，并删除桌面快捷方式。
