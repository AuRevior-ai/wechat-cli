# WeChat CLI Web 本地版

这是一个 Windows 本地工具包，用来把 WeChat CLI 的命令行能力变成网页界面。它只在本机启动 `localhost` 服务，适合不熟悉命令行的用户使用。

## 一键安装和启动

1. 解压整个压缩包。
2. 双击 `install-and-start.bat`。
3. 安装脚本会把程序复制到 `%LOCALAPPDATA%\WeChatCliWeb`。
4. 安装完成后会创建桌面快捷方式 `WeChat CLI Web`。
5. 浏览器会自动打开 `http://127.0.0.1:8787`。

使用网页控制台时，请保持弹出的命令窗口不要关闭。关闭窗口后，本地服务也会停止。

## 日常使用

安装后，直接双击桌面上的 `WeChat CLI Web` 快捷方式即可。

也可以手动运行：

```powershell
%LOCALAPPDATA%\WeChatCliWeb\start-wechat-cli-web.bat
```

## 第一次初始化

首次使用前请先打开并登录电脑版微信，然后在网页里进入“初始化”页面。

初始化会做两件事：

1. 自动查找本机微信数据目录。
2. 从正在运行的微信进程中提取本地数据库解密密钥（支持 Windows 微信 4.1+ 的口令派生方式）。

微信后续新建 `message_1.db`、`message_2.db` 等消息分库时，工具会在下次查询时自动识别并刷新密钥，不会继续静默读取旧分库。

如果同一台电脑登录过多个微信账号，初始化页面会列出检测到的多个 `db_storage` 目录。请先在下拉框中选择要读取的账号目录，再点击“开始初始化”。

如果初始化失败，请尝试：

- 确认微信正在运行并已登录。
- 右键以管理员身份运行 `start-wechat-cli-web.bat`。
- 点击“检测目录”重新扫描，或在网页初始化页面手动填写微信 `db_storage` 目录。

## 可用功能

网页端包含以下功能入口：

- 总览
- 初始化
- 聊天记录：搜索并选择会话，按整天范围读取记录，提供完整复制和精简信息复制；还可生成 AI 资料包，将合并转发递归展开，把图片、表情、语音整理到 `素材/` 目录，并让复制文本引用对应文件名
- 消息搜索
- 联系人
- 群聊成员统计和导出
- 单个聊天数据统计
- 群聊成员邀请统计：统计范围从微信数据库记载的日子开始；读取直接邀请和二维码入群提示，按唯一拉人数排行，可查看全部关系明细并下载 CSV

网页里的数据属性统一显示中文；每个左侧功能分别保存自己的结果，切换功能时不会串到其他页面。

## AI 资料包与语音识别

在“聊天记录”页选好会话和日期后，点击“生成 AI 资料包”：

1. 工具在本机生成 ZIP，不上传聊天数据。
2. ZIP 内有 `聊天记录.txt`、`清单.json` 和 `素材/`。
3. 合并转发会展开，图片和表情会保存为真实素材文件。
4. 语音会解码为 WAV；勾选语音转文字后，还会在聊天正文中加入机器识别文本。
5. 生成完成后，“复制”和“复制精简信息”都会引用 `素材/文件名`，请把复制内容和 ZIP 一起交给 AI。

首次进行语音转文字时，程序会从 sherpa-onnx 官方发布源下载约 96 MB 的 Windows 运行库和中文离线模型，校验 SHA-256 后缓存在本机；后续可离线使用。

最新版微信的 V2 图片密钥只会在微信刚打开过图片时短暂进入内存。如果结果提示某张图片缺少密钥，请在电脑版微信中把该图片点开到大图，再重新生成资料包。已获取的会话图片密钥会安全保存在本机配置中，方便后续读取。

命令行也可直接生成：

```powershell
%LOCALAPPDATA%\WeChatCliWeb\app\wechat-cli.exe ai-package "聊天名称" --start-time 2026-07-29 --end-time 2026-07-29 --output chat-ai.zip
```

## 隐私说明

本工具只绑定 `127.0.0.1`，也就是只允许本机访问。

它读取的是你电脑上的本地微信数据，不会把聊天记录上传到服务器。生成的配置和密钥保存在当前 Windows 用户目录下的 `.wechat-cli` 相关位置，请不要把这些文件发给别人。

## 常见提醒

- Windows 可能提示“未知发布者”或 SmartScreen 拦截，这是因为当前版本没有代码签名。确认来源可信后选择继续运行。
- 本版本已在 Windows 微信 `4.1.12.26` 上完成读取、统计和身份区分验收；微信更新后如数据库格式变化，请重新获取对应版本的工具包。
- AI 资料包下载使用本机一次性链接；下载后服务器端临时 ZIP 会立即删除。
- 如果浏览器没有自动打开，可以手动访问 `http://127.0.0.1:8787`。
- 如果端口被占用，请关闭其他正在运行的 WeChat CLI Web 窗口后重试。
- 如果要卸载，可以删除 `%LOCALAPPDATA%\WeChatCliWeb`，并删除桌面快捷方式。
